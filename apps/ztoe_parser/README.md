# ZTOE Parser
Додаток SLZB-OS: графік погодинних відключень **АТ «Житомиробленерго»**
([www.ztoe.com.ua](https://www.ztoe.com.ua/unhooking-search.php)) для вашої
адреси. Графік отримується на самому координаторі й розсилається іншим
Berry-скриптам через канал ISC — щоб вимкнути навантаження, надіслати
сповіщення, змінити підсвітку перед відключенням тощо.

- **Пошук за адресою** — РЕМ → населений пункт → вулиця, так само як у формі
  пошуку на сайті. У таблиці результатів видно будинки вулиці та їхню
  підчергу (черга.підчерга), кнопка **Вибрати** зберігає її. Підчергу можна
  вибрати й вручну.
- **Налаштування** — підчерга, адреса, інтервал оновлення (5–1440 хвилин),
  канал ISC і автоматичне оновлення зберігаються в
  `/beapps/ztoe_parser/config.json`. Списки РЕМів, населених пунктів і вулиць
  для збереженої адреси кешуються в `/beapps/ztoe_parser/lists.json`, тож
  відкриття сторінки додатка не робить запитів до сайту — вони потрібні лише
  під час вибору нової адреси.
- **Графік** — на сьогодні й на завтра (коли сайт його вже опублікував) у
  вигляді смуги з 48 півгодинних слотів і списку інтервалів без світла;
  поточні пів години позначені.
- **Розсилка ISC** — після кожного успішного оновлення графік надсилається у
  вибраний канал (0–100, займається як `ISC.CH_TYPE_BROADCAST`); кожен
  підписаний скрипт отримує свою копію.

## Вимоги
- Координатор на ESP32-S3 (серії U, MRU, Ultima) з SLZB-OS **v3.4.2.dev1** або
  новішою (виправлений `HTTP.streamReadString()`) і доступом до інтернету.
- Увімкніть **Start on boot** на картці додатка, щоб графік оновлювався й
  розсилався без відкритої сторінки додатка.

## Повідомлення ISC
JSON-рядок:

```json
{
  "queue": "3.1",
  "updated": "23:00 30.09.2026",
  "days": [
    {"date": "30.09.2026", "slots": "000000…", "off": []},
    {"date": "01.10.2026", "slots": "000…111…", "off": [{"start": 1900, "end": 2100}]}
  ]
}
```

| Поле | Опис |
|------|------|
| `queue` | Підчерга, `"черга.підчерга"` |
| `updated` | Коли сайт оновив графік (`"ГГ:ХХ ДД.ММ.РРРР"`) |
| `days[].date` | `"ДД.ММ.РРРР"`; спочатку сьогодні, далі завтра, якщо вже опубліковано |
| `days[].slots` | 48 символів, по одному на кожні пів години від 00:00: `1` — світла немає, `0` — світло є |
| `days[].off` | Інтервали без світла, час — ціле число `ГГХХ` (`800` = 08:00, `2400` = кінець доби) |

```berry
import ISC
import json

ISC.subscribe(10)   # канал, вибраний у додатку

while true
    var s = json.load(ISC.receive(10, ISC.TIMEOUT_FOREVER))
    for d: s["days"]
        for o: d["off"]
            SLZB.log(d["date"] .. ": світла не буде " .. o["start"] .. " - " .. o["end"])
        end
    end
end
```

Розсилку отримують лише скрипти, підписані на канал у цей момент — скрипт,
запущений пізніше, отримає графік з наступним оновленням. Щоб надіслати його
одразу, натисніть **Оновити зараз** на сторінці додатка.

## Як це працює
- Сайт — звичайний HTML у кодуванні windows-1251. Бекенд (`app.be`) читає
  його модулем `HTTP` у потоковому режимі шматками по 2 КБ, перевіряючи кожне
  читання на кінець відповіді, і закриває з'єднання, щойно отримав потрібне
  (уся сторінка — близько 480 КБ).
- Списки адрес: форма надсилається так само, як на сайті (`rem_id`,
  `naspunkt_id`, `vulica_id`); варіанти наступного списку й таблиця
  результатів передаються на сторінку сирими байтами windows-1251 у base64, а
  сторінка розкодовує їх через `TextDecoder("windows-1251")`.
- Графік: на звичайній сторінці є дві таблиці (`<!--0<br>-->` — сьогодні,
  `<!--1<br>-->` — завтра); рядок підчерги — той, що містить посилання
  `pidcherga_id=<(черга−1)·2+підчерга>`, слоти — його останні 48 клітинок
  (у рядках X.1 на одну клітинку більше, ніж у X.2), слот із не білим фоном
  означає відключення.

## Файли
| Файл | Призначення |
|------|-------------|
| `meta.json` | Маніфест додатка (`folder: ztoe_parser`, додаткові дозволи не потрібні) |
| `ui.html` | Сторінка додатка: пошук адреси, налаштування, графік, приклад скрипта |
| `app.be` | Berry-бекенд: розбір сайту, конфіг, інтервал, розсилка ISC |
| `icon.png` | Іконка для списку додатків |

## Встановлення
Встановіть через **Apps → APPS repository** у веб-інтерфейсі координатора або
через **Apps → Local APP installer** з архівом `dist/ztoe_parser.zip`.
Файли розпаковуються в `/beapps/ztoe_parser/` на пристрої.
