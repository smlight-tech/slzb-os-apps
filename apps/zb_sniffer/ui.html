Zigbee encrypts the network layer, so this page decodes the MAC and NWK headers only (APS / ZCL too for the rare frames without NWK security). Click a row for all fields and the raw bytes. For full decoding send the packets to Wireshark and add the network key there.

How to watch the traffic in Wireshark
  1. Enable Send to Wireshark and enter the IP address of the PC that runs Wireshark (port 17754).
  2. Start a capture in Wireshark on the network interface of that PC and use the display filter zep. Wireshark decodes ZEP on UDP port 17754 by itself, no listening program is needed.
  3. To decrypt the network layer add the network key in Edit → Preferences → Protocols → ZigBee → Pre-configured Keys (Zigbee2MQTT: network_key in configuration.yaml, as 16 hex bytes). Add 5A:69:67:42:65:65:41:6C:6C:69:61:6E:63:65:30:39 (ZigBeeAlliance09) too to see the keys handed out while devices join.

The radio only listens (manufacturing library receive mode) and never transmits, but it cannot be a coordinator at the same time: to sniff your own network use a second radio of a multi-radio device, or a coordinator that is not the one running the network.
